Frequently asked questions
Still have questions?
Questions before you start
Do I need to change my tools to use CodeQ?
Usually not. If your tool supports a custom API endpoint, set the base URL, API key and model name. Check the integration guide for supported features.
Which model should I start with?
Start with a familiar model and a small real task. Compare correctness for code and style for writing. Check the model list for versions and pricing.
Where can I see request logs and usage?
Sign in to the console to review request logs, usage details and your balance.
Does the workbench send real requests?
No. It only displays code examples. Copy an example, configure your key and run it in your own application.
